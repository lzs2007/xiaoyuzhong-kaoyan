# 院校名录（小语种考研）

逐校核实"哪些院校的哪些专业接受 202 俄语 / 203 日语"，每所院校均附**官方专业目录来源、原文摘录与适用年份**，无需你自己翻遍研招网。

::: danger 使用前必读
- 本名录为**辅助参考**，最终报考前仍须以**当年研招网硕士专业目录 + 院校官方招生简章**为唯一依据——语种可选范围**每年可能调整**（例：大连交通大学 2026 年起已大面积取消工科俄/日语选项）。
- "部分专业可选"表示该校仅部分工科专业可选，请务必点开"来源与详情"查看具体范围。
:::
