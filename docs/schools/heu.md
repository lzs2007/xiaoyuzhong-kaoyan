## 三、重要提示：专项方向多仅考英语

哈工程设有多个异地/专项培养方向，这些方向**多数只考 201 英语（一）**，报考时极易踩坑。已在官方目录中核实到的限制方向包括：

- **青岛创新发展基地专项**（船舶、航建、动力、智能、水声、计算机、信通、材料、物理光电等学院多个专业）
- **海南（三亚）专项**（船舶 082401、智能 081100、水声 082403/085400、核科学 085800 等）
- **长三角研究院（南通）专项**（船舶 082401、085900、智能 085400 等）
- **龙江工程师学院专项**（船舶 085900 等）
- **烟台研究院（051）全部专业**：085400 电子信息、085600 材料与化工、085800 能源动力、085900 土木水利、085500 机械，**均仅考英语，未列入本页**。

> 结论：报考哈工程时，**不能只看专业，必须精确到"专业 + 研究方向"**再核对语种。

## 四、几类容易混淆的情况

**Q1：外国语言文学（050200）下的"俄语语言文学"方向，能考 202 俄语吗？**
不能。该方向属于**外语专业**，其外国语考的是**第二外语**（自命题科目），并非全国统考 202 俄语，因此未列入本页。

**Q2：单独考试考生也用 202 俄语吗？**
不用。哈工程《2026年硕士单独考试招生专业目录》中外国语为 **245 单独考试英语 / 246 单独考试俄语 / 247 单独考试日语**，属于单独考试自命题科目，与统考 202 俄语不是同一科目。

**Q3：表格里的"2+6/0"是什么意思？**
为哈工程官方目录的招生人数口径：**推免拟接收人数 + 统考预计招收人数 / 非全日制人数**。该数字为学校按上一年实际录取情况拟定的计划，仅供比较参考，最终以国家下达计划与推免接收情况动态调整。
