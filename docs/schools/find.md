# 按专业找院校

选择招生年度与初试语种，输入目标专业，查找有明确目录依据的院校及研究方向。

<MajorSearch />

::: warning 使用说明
仅查询外国语是否可选202俄语或203日语，不代表满足全部报考条件。学习方式、专项资格、校区及复试要求仍需核对当年官方目录。各院校的专业未全部收录，请勿将无匹配结果理解为不可报考。
:::

需要浏览其他学校？查看[院校名录概览](/schools/)。概览中的学校级语种标签不会自动生成专业查询结果。
