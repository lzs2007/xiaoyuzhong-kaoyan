# 专业查询数据维护说明

## 年度与来源

- 2026：继承本站2026-09-12两校官方目录整理记录，仅迁移工学专业，共70个专业项（含同专业不同学院及专项记录）。语言选项逐项读取外国语原文，不从俄语文件名推断日语可选性。本次结构迁移不代表重新核验全部官方原件。
- 2027（2026-11-03检查）：吉林大学[信息公开网招生章程及目录公告](https://gongkai.jlu.edu.cn/info/1040/14566.htm)已找到，专业与方向尚未完成逐项核验，标记“待更新”。哈工程[官方专业目录栏目](https://yzb.hrbeu.edu.cn/3277/list.htm)与旧目录页未能取得可核验的完整目录内容，标记“待更新”。均不生成2027匹配结果，不声称目录尚未发布。

## 新年度接入

1. 从当年官方目录逐项录入院校、学院、专业代码、专业名、方向、学习方式、计划或专项、外国语原文及科目代码。缺失学习方式不猜测；同代码不同院系、校区或专项不得合并限制。
2. 每项保留来源名称、链接、采集日期、核实状态及目录页码或“附件→学院→专业→方向”的定位信息。人数保留原文口径，不直接求和混合专业与方向人数。
3. 仅将已核验且明确接受对应语种的方向纳入结果，更新年度覆盖状态。部分收录必须标注覆盖范围，未收录不等于不可报考。
4. 运行构建、查询测试并核对详情定位。保留2026历史数据与现有详情URL；新年度链接应指向对应年度详情，不使用2026页面作2027依据。

## 旧数据边界

吉林大学原记录将部分方向拼接在专业名称内，迁移时拆开并保留完整原文。退役士兵专项未单列学习方式，不推断为普通全日制。哈工程仅英语方向旧数据未保留具体英语科目代码，展示该事实并引导核对原件。省份为院校所属信息，异地培养基地名称保留在方向或学院原文内，不代表实际就读地点。

详情锚点由学院、专业原文及计划共同生成，重排不改变链接；修改身份字段时需保留旧锚点重定向。测试会核验每个查询结果均可定位至详情原条目。
