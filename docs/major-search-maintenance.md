# 专业查询数据维护说明

## 年度与来源

- 2026：继承本站2026-09-12两校官方目录整理记录，仅迁移工学专业，共70个专业项（含同专业不同学院及专项记录）。语言选项逐项读取外国语原文，不从俄语文件名推断日语可选性。本次结构迁移不代表重新核验全部官方原件。
- 2027初始状态（2026-11-03首版）：吉林大学[信息公开网招生章程及目录公告](https://gongkai.jlu.edu.cn/info/1040/14566.htm)已找到，专业与方向尚未完成逐项核验，标记“待更新”。哈工程[官方专业目录栏目](https://yzb.hrbeu.edu.cn/3277/list.htm)与旧目录页未能取得可核验的完整目录内容，标记“待更新”。均不生成2027匹配结果，不声称目录尚未发布。

## 新年度接入

1. 从当年官方目录逐项录入院校、学院、专业代码、专业名、方向、学习方式、计划或专项、外国语原文及科目代码。缺失学习方式不猜测；同代码不同院系、校区或专项不得合并限制。
2. 每项保留来源名称、链接、采集日期、核实状态及目录页码或“附件→学院→专业→方向”的定位信息。人数保留原文口径，不直接求和混合专业与方向人数。
3. 仅将已核验且明确接受对应语种的方向纳入结果，更新年度覆盖状态。部分收录必须标注覆盖范围，未收录不等于不可报考。
4. 运行构建、查询测试并核对详情定位。保留2026历史数据与现有详情URL；新年度链接应指向对应年度详情，不使用2026页面作2027依据。

## 旧数据边界

吉林大学原记录将部分方向拼接在专业名称内，迁移时拆开并保留完整原文。退役士兵专项未单列学习方式，不推断为普通全日制。哈工程仅英语方向旧数据未保留具体英语科目代码，展示该事实并引导核对原件。省份为院校所属信息，异地培养基地名称保留在方向或学院原文内，不代表实际就读地点。

详情锚点由学院、专业原文及计划共同生成，重排不改变链接；修改身份字段时需保留旧锚点重定向。测试会核验每个查询结果均可定位至详情原条目。

## 2027官方原件采集批次（2026-11-03）

新增8个来源、7校、201个专业核验项，其中124项的287个方向明确接受202俄语。来源包括哈工大31页官方PDF、哈理工5页官方PDF、北理工XLS、辽宁工业与辽宁科技HTML表、吉大电子学院HTML及长春理工官网目录图片。

- 仪器：哈工大080400及仪器学院085400、哈理工080400/085407、北理工080400。哈理工两项仅202及英语，不支持203。
- 机械：长春理工080200/085500、辽宁工业080200/085501等；哈工大各基地须逐方向查看；哈理工085500仅05产品智能交互与人因设计方向接受俄语，其余方向/专项仅英语。
- 明确限制：北理工机械学硕所列相关学院方向含203而无202；长春理工光电学院仪器类仅英语；吉大电子学院本页两项学硕仅英语、两项专硕可选202/203。均不以旧年度或同校其他学院结论推断。
- 哈工程2027与沈阳工业大学2027尚未取得可核验的完整原件（后者附件返回验证码页面），不新增可选结论；既有2026数据保持原年。

采集工具：`npm run collect:catalogs -- --list` 查看来源；运行后只输出待核验候选。源文件摘要与覆盖范围在 `catalogSources.json`，已核验方向在 `reviewedPrograms.ts`。每个方向的初试外国语独立存储，不由院系代码202或普通俄语专业名称判定。

## 东北三省扩展批次（2026-11-03）

新增哈工程、黑龙江科技大学、辽宁石油化工大学、东北大学、北京科技大学、中国石油大学（北京）6校214个核验项，其中102项、154个方向明确接受202俄语。合计2027年度13校415个核验项，226项、441个方向接受202俄语。东北三省有10所已收录可选202的院校，216个专业项；不是东北全部院校或全部可报专业的完整名单。

- 哈工程：正式简章附件32页统考目录，按同一表格中各方向对应的(1)—(4)科目块逐一配对；方向数与科目块数不一致时拒绝录入。全日制与非全日制分项，不沿用旧年专项限制。例如2027船舶学院土木水利的海南专项可选202，而同专业青岛方向仍仅英语。
- 黑龙江科技大学：机械、电气、材料、计算机应用技术、控制工程等部分专业明确接受202；仅第1—11页普通统考目录用于语种判断，第12页工程师联合培养清单没有独立科目，不据此扩展资格。
- 辽宁石油化工大学：机械学院机械工程、机械、动力、材料等可选202；其他学院仅英语的专业保留排除记录，不以学校层面推断。
- 东北大学：使用含考试科目的HTML目录；简章中的21页拟招生人数PDF不含考试科目，不能作为语种依据。核验可选202的工科集中在冶金学院，不外推到机械、控制、计算机。
- 北京科技大学：全日制目录的资源与安全工程学院力学只有部分方向接受202；安全科学与工程、安全工程有明确依据。其他院系同名专业不共用结论。
- 中国石油大学（北京）：仅全日制学术学位目录，地球科学学院地质资源、石油工程学院力学与石油天然气工程有202依据；地球物理学院同代码地质资源专业仅英语。

本批原文结构在 `reviewedExpansionPrograms.ts`，来源及指纹在 `catalogSources.json`。实际检查过但尚未取得完整可核验原件的学校记录在 `catalogReviewQueue.json`；验证页面、403、503及待复核都不等于不可报考。哈工程已移出待更新清单。
