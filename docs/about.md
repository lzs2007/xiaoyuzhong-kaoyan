# 关于与免责声明

## 本站定位

本站是**非官方**的小语种考研信息整理站，聚焦**考研俄语 202** 与 **日语 203**，面向考生提供可溯源的官方信息整理与查询指引。本站不代表任何政府机构、教育考试机构或招生单位。

## 信息来源规范

本站信息优先采用以下权威渠道，并按优先级排序（冲突时从高到低）：

1. 中国研究生招生信息网（研招网）、教育部官网
2. 教育部教育考试院、省级教育招生考试机构
3. 各招生单位研究生院/研招官网（招生简章、专业目录、考试大纲、复试调剂公告）
4. 官方考试大纲及权威出版物
5. 机构整理/经验类内容（仅作参考，强制标注“非官方”标签）

**每条关键信息均标注**：信息类型、来源名称、来源链接、发布时间、采集/更新日期、适用年份、核实状态、备注。

**核实流程**：关键政策（国家线、报名时间、大纲变动等）须经至少两个权威来源交叉验证；无法核实的信息一律标注“待核实”；禁止编造与无来源断言。

**年份规范**：涉及年份的信息强制标注适用年份（如“2026考研”“2025年国家线”）。

## 版权说明

- 本站**不托管、不转载**真题原文与考试大纲原文，仅提供摘要、结构说明与官方/正版获取渠道；
- 政策类内容为官方公开发布信息的整理与摘要，均已标注来源与原文链接；
- 如存在版权问题，请通过纠错渠道联系，核实后第一时间处理。

## 免责声明

- 本站信息仅供学习参考，**不构成任何报考建议**；
- 招生单位是否接受 202 俄语 / 203 日语、考试科目、分数线等，**一律以当年中国研究生招生信息网硕士专业目录和招生单位官方招生简章/公告为准**；
- 因信息更新滞后或官方政策调整导致的差异，以官方最新公告为准，本站不承担由此产生的后果。
