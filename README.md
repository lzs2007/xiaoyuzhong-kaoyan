# 小语种考研信息网

> 旨在帮助小语种考生考研择校。
>
> 聚焦考研**俄语（202）**与**日语（203）**的非官方信息整理站：把散落在研招网与各院校官网的关键信息集中起来，**逐条标注来源**，让你少翻几十个网站。

🌐 在线访问：**<https://lzs2007.github.io/xiaoyuzhong-kaoyan/>**

> 本站为非官方整理项目，不构成任何报考建议。招生单位是否接受 202 俄语 / 203 日语，**必须以当年中国研究生招生信息网（研招网）硕士专业目录与院校官方招生简章为唯一依据**。

---

## 这个站点解决什么问题

小语种考生最大的痛点不是“学不会”，而是**信息极度分散**：某个专业到底能不能用俄语 202 报考，往往要翻遍研招网、院校研究生院官网、学院分册目录，甚至只能靠经验帖猜测，而且**每年都可能变**。

本站做的事很朴素：**把官方目录翻出来，逐校、逐专业核实，再把来源原样摆出来。**

## 信息来源原则

本站所有关键信息遵循同一套规范，力求“**每条结论都能点回原文**”：

1. **官方优先**：以研招网公告、院校研究生院官网发布的招生章程与专业目录原件为准；
2. **标注来源**：每条信息附来源名称、链接、适用年份、采集日期与核实状态；
3. **区分性质**：明确区分「官方」「机构整理/经验」两类内容，经验类内容仅供参考；
4. **多人交叉**：单源信息经多方转载交叉比对；官方附件受验证码限制无法解析时，明确标注为“单源”；
5. **尊重版权**：不转载考试大纲与真题原文，仅提供摘要与官方/正版获取渠道。

## 技术栈

- **[VitePress](https://vitepress.dev/)** —— 静态站点生成，Markdown 内容 + Vue 组件增强
- **Vue 3 + TypeScript** —— 院校名录、吉林大学专业清单等交互式表格组件
- **GitHub Actions + GitHub Pages** —— 推送 `main` 即自动构建发布，无需服务器

## 本地开发

```bash

```

## 专业查询维护

专业查询采用 `docs/.vitepress/data/majorSearch.ts` 的统一接口，方向包含独立语种与学习方式，来源包含官方链接、定位、年度与核实状态。旧专业数据通过适配器接入，仅将明确的202/203科目代码作为可选依据；仅英语方向不猜测具体英语代码，专项学习方式不明确时显示待核实。首批为吉大26项、哈工程44项工学数据，不构成全国完整专业目录。

2027数据状态与核验记录见 [专业查询数据维护说明](docs/major-search-maintenance.md)。新增年度必须录入该年度官方依据及方向信息，不得复制旧年度结论。旧详情页的定位锚点按学院、专业原文与计划生成，重排数组不会改变链接；修改条目身份字段时应保留旧锚点重定向。

验证：使用 Node.js 22.18+，执行 `npm ci`、`npm run docs:build`、`npm test`。测试涵盖年度隔离、语种独立、方向限制、专项、组合筛选、分享参数与生产详情锚点。

## 官方目录搜集工具

2027新批次来源：哈工大、哈理工、北理工、辽宁工业大学、辽宁科技大学、长春理工、吉林大学（电子学院部分）。共核验201个专业项，其中124项至少有一个方向接受202俄语，其他明确限制保留在采集记录页。此处专业项按学院和学习方式分别计数，不是唯一专业代码数。2026旧数据仍独立保留。

```bash
python3 -m pip install -r scripts/requirements-catalogs.txt
npm run collect:catalogs -- --list
npm run collect:catalogs -- --source hrbust-2027 --source bit-2027
```

工具按 `docs/.vitepress/data/catalogSources.json` 抓取官方HTML、PDF、XLS或图片，将原件、SHA-256、202候选上下文和错误记录保存到忽略目录 `.cache/catalog-collection/`。候选始终为待核实，不直接写入已发布查询库；验证码、解析失败及零候选均不解释为不可报考。图片须人工阅读核验。

复核后将结构化方向录入 `reviewedPrograms.ts`，每方向保留外国语原文、初试科目、人数口径与行/页定位，再运行构建和测试。来源指纹变化仅提示需复核，HTML计数器变化也可能造成指纹不同。
